# Don Telmo Estilos

Repositorio de referencia para identidad visual, tokens, patrones de interfaz y buenas prácticas de composición de los sistemas Don Telmo. El núcleo es agnóstico al framework; los adaptadores y ejemplos se agregan por tecnología cuando se validen.

## Contenido

- `docs/identidad-visual.md`: hallazgos actuales y dirección visual común.
- `docs/arquitectura-ui.md`: modularidad, composición y contratos de componentes.
- `docs/uso-del-sistema.md`: cómo adoptar y extender los tokens.
- `templates/css/`: punto de partida portable con variables CSS y temas.
- `skills/don-telmo-ui/SKILL.md`: guía operativa para implementar interfaces en los sistemas.

## Estado de la información

Los valores indicados como **observados** vienen de los estilos actuales del CRM o BotApp. Las recomendaciones marcadas **propuesta** son una base común para validar antes de propagar a aplicaciones existentes. Este repositorio documenta y distribuye lineamientos; no modifica por sí solo los sistemas consumidores.
